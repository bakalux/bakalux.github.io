# Happy Birthday

Интерактивное поздравление на React: фейерверки, шуточная викторина, барабан «Поле чудес» и финальный приз.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой на GitHub Pages

Workflow лежит в `.github/workflows/deploy.yml`. После пуша в `main` GitHub Actions соберет проект и выложит содержимое `dist` в GitHub Pages.
